# CloudForge Observability Update

Bu paket mevcut `cloudforge-demo-app` projesine Prometheus ve Grafana ekler.

## Servis adresleri

- Application: http://localhost:8080
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000

## Grafana local giriş

- Kullanıcı: `admin`
- Parola: `cloudforge`

Bu parola yalnızca local development içindir.
