# User Stories

## Authentication

### US-AUTH-001

**Bir platform kullanıcısı olarak**, uygulamalarımı yönetebilmek için güvenli hesap oluşturmak istiyorum.

### US-AUTH-002

**Bir platform kullanıcısı olarak**, yalnızca kendi kaynaklarıma erişebilmek için giriş yapmak istiyorum.

## Application Management

### US-APP-001

**Bir platform kullanıcısı olarak**, GitHub repository'mi tanıtabilmek için yeni uygulama oluşturmak istiyorum.

### US-APP-002

**Bir platform kullanıcısı olarak**, aktif sürümü, durumu ve URL'yi tek ekranda görmek istiyorum.

### US-APP-003

**Bir platform kullanıcısı olarak**, artık kullanmadığım uygulamayı kontrollü şekilde silebilmek istiyorum.

## CI/CD

### US-CI-001

**Bir geliştirici olarak**, hatalı kodun deploy edilmesini engellemek için her push'ta testlerin otomatik çalışmasını istiyorum.

### US-CI-002

**Bir geliştirici olarak**, dağıtımın tekrar üretilebilir olması için image'ın commit SHA ile etiketlenmesini istiyorum.

### US-CD-001

**Bir platform kullanıcısı olarak**, yeni sürüm production'a geçmeden staging ortamında doğrulansın istiyorum.

### US-CD-002

**Bir platform kullanıcısı olarak**, deployment'ın hangi aşamada olduğunu görmek istiyorum.

## Observability

### US-OBS-001

**Bir platform kullanıcısı olarak**, hata oranı ve yanıt süresini dashboard üzerinden görmek istiyorum.

### US-OBS-002

**Bir platform kullanıcısı olarak**, başarısız deployment nedenini anlayabilmek için logları görmek istiyorum.

## Reliability

### US-REL-001

**Bir platform kullanıcısı olarak**, sorunlu sürümden önceki başarılı sürüme dönebilmek istiyorum.

### US-REL-002

**Bir platform kullanıcısı olarak**, hata oranı kritik seviyeye çıktığında sistemin otomatik rollback yapmasını istiyorum.

### US-REL-003

**Bir platform kullanıcısı olarak**, yoğun trafik sırasında uygulamanın otomatik ölçeklenmesini istiyorum.

## Security

### US-SEC-001

**Bir platform kullanıcısı olarak**, secret bilgilerimi kaynak kod dışında güvenli biçimde yönetmek istiyorum.

### US-SEC-002

**Bir administrator olarak**, kritik açığı bulunan image'ın production'a ulaşmasını engellemek istiyorum.
